# US05 - Available meeting time slots
Source: workspace US05. Branch: feature/US05-available-time-slots-backend.

GET /api/participants lists active project users.
POST /api/availability accepts {date, participantIds: [String user IDs], durationMinutes}.
Returns non-overlapping slots within 08:00-17:00 in project local time.
Uses existing user, meeting and meeting_participant tables. Organizer commitments are included.
Cancelled meetings and declined/removed participants do not block availability.
Busy intervals are merged and clipped against the requested day, including overnight meetings.
No alternate Meeting/Participant entities, Flyway demo migrations or static frontend files are imported.
