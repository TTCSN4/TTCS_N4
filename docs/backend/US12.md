# US12 - Book equipment with a meeting
Source: workspace US12. Branch: feature/US12-book-equipment-backend.

Develop already contains the source equipment CRUD/reservation endpoints; they are preserved.
The ERD meeting_equipment association now has the composite key (meeting_id,equipment_id).
POST /api/meetings/{meetingId}/equipment accepts {equipmentId,quantity} and creates or replaces the reservation.
GET lists association quantities; DELETE /{equipmentId} releases the reservation and association.
Only the authenticated organizer can reserve/release equipment for future active meetings.
Meeting and equipment locks protect concurrent updates. Capacity uses peak overlapping usage, including maintenance.
Each association also writes the existing equipment_bookings extension used by develop's status APIs.
US02 cancellation releases those reservations. Association rows remain available as historical meeting data.
No duplicate model/Equipment or controller/EquipmentController, H2 data files or static assets are imported.
