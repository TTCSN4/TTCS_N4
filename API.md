# API và cách chạy

Bản web hiện tại chạy bằng `node server.cjs`, phục vụ giao diện trong `src/main/resources/static` và API dùng chung trong `tools/web/demo-api.cjs`.

Mã Java nghiệp vụ nằm trong `src/main/java/com/ttcs/meetingmanagement`. Các hợp đồng Java chi tiết theo US nằm trong `docs/backend`.

Xem README.md để clone, cài dependency, chạy web, build Java và chọn nơi lưu dữ liệu.
