# US02 - Update and cancel meetings

Source: workspace US02. Branch: feature/US02-update-meeting-backend.

Uses the develop application's String identifiers, singular ERD tables and LocalDateTime (Asia/Ho_Chi_Minh).
The standalone com.example application, frontend, demo database and build output are not imported.

PUT /api/meetings/{id}: title, description, startTime, endTime, optional roomId.
DELETE /api/meetings/{id}?reason=...: cancels a future scheduled meeting.
GET /api/meetings/{id}: reads the meeting.

The actor comes from authenticated JWT subject or AuthenticatedUserIdentity, never X-User-Id.
Only the organizer may edit/cancel. Updates lock the meeting and selected room, reject conflicting room bookings,
and release old equipment reservations when room/time changes. Cancellation releases equipment reservations.

This branch also repairs the pre-existing develop build and supplies common ERD entities/repository methods.
These changes are reused unchanged by the other backend branches to reduce merge conflicts.
