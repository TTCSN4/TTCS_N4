# US13 - Equipment availability
Source: workspace US13. Branch: feature/US13-equipment-status-backend.

Develop already contains the source status/maintenance endpoints, which remain unchanged.
GET /api/equipment/availability?room=...&startTime=...&endTime=... adds availability for an entire requested interval.
Uses the existing equipment/equipment_bookings entities. No duplicate application, repositories or frontend are copied.
The returned availableQuantity is total minus peak simultaneous usage, rather than sum of disjoint bookings.
Back-to-back bookings do not overlap. Cancelled reservations/meetings are excluded.
Static maintenance/inactive states and scheduled maintenance are respected.
Read access follows the shared attendee/booker/admin RBAC policy.
