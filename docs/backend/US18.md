# US18 - Create users
Source: workspace US18. Branch: feature/US18-create-user-backend.

Uses shared user, role and department entities; no second application or frontend is imported.
POST /api/users creates an ACTIVE account, normalizes email, validates role/department, rejects duplicate email,
and hashes passwords with BCrypt. GET /api/users returns a DTO without the password hash.
GET /api/roles and /api/departments return existing lookup data. These endpoints require an authenticated Admin.
Provision roles and departments in the project database; feature startup never inserts demo users.
String IDs and LocalDateTime follow develop and ERD_code.txt.
