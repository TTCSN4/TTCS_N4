# US25 - Chatbot room booking
Source: workspace US25. Branch: feature/US25-chatbot-room-booking-backend.

POST /api/chatbot/message and /api/chatbot/book-room implement conversation and direct booking.
GET /api/chatbot/rooms/available returns room options. Existing room/meeting endpoints remain owned by develop.
Uses singular shared meeting, room, user, meeting_participant tables and String IDs.
API local timestamps follow Asia/Ho_Chi_Minh. Conversation input also accepts offset timestamps and Vietnamese date/time.
The authenticated actor owns the conversation and must be the booking organizer.
Locks candidate rooms and rechecks capacity/overlap before saving. No demo data or frontend is copied.
GEMINI_API_KEY enables AI parsing; local conversational fallback remains available without the key.
Feature configuration lives in application-us25.properties, keeping the shared datasource configuration unchanged.
